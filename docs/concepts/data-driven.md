# Data-driven design

ark separates metadata, configuration and runtime Entity values. Metadata describes fields and tables; configuration supplies values; modules respond to Entity and data events.

![Data-driven event flow](../assets/data-node-sample.png)

Read [data structures](../guides/data-structures.md) for Node, Table and Container relationships, and [Kernel](../reference/kernel.md) for event registration and data access. Configuration generation is described under [tools](../guides/tools.md).
